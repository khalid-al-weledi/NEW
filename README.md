
# مقرأة الإمام الجزري للإقراء والإجازة بالسند

Imam Al-Jazari Maqraah for Quranic Recitation and Ijazah with Sanad

## أهداف المشروع

- موقع تعريفي للمقرأة.
- تسجيل الطلاب ومراجعة الطلبات.
- البرامج والباقات.
- المدفوعات وأرصدة الدقائق.
- لوحة إدارة وإحصائيات.
- نشر مقاطع قرآنية قصيرة.
- واجهة عربية متجاوبة مع الهواتف.

## المتطلبات

- Node.js 20 أو أحدث.
- npm.
- PostgreSQL.
- متغير DATABASE_URL صالح.

## التثبيت

1. انسخ المشروع.
2. ثبّت الحزم باستخدام npm install.
3. أنشئ ملف .env من .env.example.
4. ضع بيانات PostgreSQL في DATABASE_URL.
5. نفّذ npx prisma generate.
6. أنشئ أول migration باستخدام npx prisma migrate dev --name init.
7. شغّل npm run dev.
